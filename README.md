Azure Repos is a set of version control tools that you can use to manage your code. Whether your software project is large or small, using version control as soon as possible is a good idea.

**Areas:** Developer Tools · DevOps · Version Control · Repositories · TFVC

## Azure Repos on APIs.io

Everything profiled for Azure Repos is published on APIs.io rather than in this repository. Start at the provider page — **[apis.io/providers/microsoft-azure-repo/](https://apis.io/providers/microsoft-azure-repo/)** — or go straight to one of the APIs or properties below.

### APIs (9)

- [Azure Repos Commits API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-commits-api/) — Operations for accessing commit details and commit history within a repository, including diffs and changes.
- [Azure Repos Items API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-items-api/) — Operations for retrieving files, folders, and submodules from a repository. Files are blobs, folders are trees.
- [Azure Repos Pull Request Reviewers API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-pull-request-reviewers-api/) — Operations for managing reviewers on pull requests, including adding, removing, and updating reviewer votes.
- [Azure Repos Pull Request Threads API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-pull-request-threads-api/) — Operations for managing comment threads on pull requests, including creating threads and replying to comments.
- [Azure Repos Pull Requests API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-pull-requests-api/) — Operations for creating, retrieving, updating, and completing pull requests. Includes managing reviewers, labels, and merge options.
- [Azure Repos Pushes API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-pushes-api/) — Operations for listing and creating pushes, which represent one or more commits pushed to a repository branch.
- [Azure Repos Refs API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-refs-api/) — Operations for managing branches and tags (refs) including listing, creating, updating, and deleting refs.
- [Azure Repos Repositories API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-repositories-api/) — Operations for managing Git repositories including creating, listing, updating, and deleting repositories within a project.
- [Azure Repos Stats API](https://apis.io/apis/microsoft-azure-repo/microsoft-azure-repo-stats-api/) — Operations for retrieving branch statistics such as commit counts ahead and behind relative to the default branch.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Azure Repos: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
